This project is a battle engine for a text based rouquelike dungeon crawler game,
the game is broken down by dungeon floors and rooms, every floor has 5 rooms, the last one being a bossfight,
the heroes can level up and get stronger as they gain XP and kill more monsters
the 4 different types of heroes ae Warrior, Mage, Healer, Tank,
the current version you start with 3, a warrior, mage, and tank.
the combat is simple, you have will select an attack and it will use stamina or mana, as stamina decreases your chances of missing an attack increase.
